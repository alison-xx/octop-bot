使用指南

请 Chief 帮你整理一次会议。

准备一小段会议记录就够了。先让 Chief 试做一份待办表，再决定哪些工作值得交给专门的 Bot。

1

选工作地点

直接登录网页版，或安装桌面版处理本机资料。两边分别保存各自的对话。

打开网页版 →
2

连接模型

网页版使用灵策账号。桌面版还可以选择自己的 API Key 或已运行的本机模型。需要 Chief 建群时，选支持工具调用的模型。

3

贴上记录和要求

在通讯录打开 Chief，贴上记录，告诉它「按事项、负责人、截止日期做一张表。没定下来的标为待确认。」

4

核对并取回结果

逐行核对姓名和日期。要拿到文件，可以继续说「保存为 CSV 给我」。从文件卡片下载并打开检查。在桌面端，也可以去 Bot 的工作目录找文件。

常见问题

你可能想知道。

应该选网页版还是桌面版？

从浏览器登录灵策即可使用云端 Bot。材料只在这台电脑、需要运行本机脚本，或打算用本机模型时，安装桌面版并创建本机 Bot。

按设备选择版本 →

怎样让不同的 Bot 分工？

告诉 Chief 你需要哪些角色。它可以查找已有成员、补建专家并创建群聊。在群里用 @ 指定成员，或在 Goal 中写下分工与验收条件。

怎样写一个能验收的群 Goal？

以读书会招募为例，在 Goal 中写下分工和验收条件：策划给三个角度，你选定后，写手交付一段 80–120 字的招募文案，管理员逐项核对面向谁、何时举行、如何报名。之后重开群聊，也能按阶段查看各成员的回复和依据。

怎样共享资料，同时保留各自的私聊？

把公共材料作为群附件发送，或在群输入框选择本群已有文件。成员能围绕同一份资料工作，把定下来的事情写进群笔记，同时保留各自的会话和工作目录。

怎样找回上次定下来的事情？

按 Ctrl+K 搜索通讯录，切到「历史私聊」，输入标题或消息关键词即可重开会话。在私聊中还可以用「引用对话」插入某段原话。

关掉自己的电脑后，任务还会运行吗？

本机任务需要电脑保持唤醒，Octop 服务也要运行。云端 Bot 已接收的任务由服务器执行。需要你登录网站或回答问题时，回到云端对话处理后再继续。

为什么在手机上找不到桌面上的这段对话？

先核对登录账号和连接的服务器。本机 Bot 的历史保存在这台电脑上。要在手机和电脑间接着做，使用同一灵策账号的云端 Bot，或让两个客户端连接同一台自建服务器。

遇到登录或验证码，怎样接管？

在网页版打开云端 Bot 的电脑画面，点「接管」，自己在页面完成登录或验证。点「交还给 Bot」后回到对话。如果 Bot 仍在等答复，告诉它已完成，可以继续。密码和验证码直接填在网站里。

核对网页和整理本机表格，分别在哪做？

核对报名网站可以从网页版找云端 Bot，把网址和要查的字段发过去。表格只在本机时，使用桌面端的本机 Bot，发给它要处理的文件，要求把修改另存为新文件。

怎样选择和安装客户端？

Windows x64 可以用 EXE 按向导安装，或完整解压 ZIP 后双击里面的 Octop Bot.exe，并保留同目录的资源文件。使用 Apple 芯片的 Mac 请打开 DMG，将 Octop Bot 拖到「应用程序」文件夹，再从那里启动。

怎样核对下载的安装包？

在下载页找到对应系统、版本和文件名，比较页面公布的 SHA-256 与本地文件的校验值。Windows 可使用 PowerShell 的 Get-FileHash，Mac 可使用 shasum -a 256。

查看安装包 →

哪些使用方式会产生费用？

客户端免费开源。使用灵策模型或运行云电脑会消耗灵策积分。桌面端使用自己的 API Key 时，模型用量按对应服务商的规则结算。
