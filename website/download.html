安装前

你需要准备什么。

一台合适的电脑

Windows 10 / 11（x64），或搭载 Apple 芯片（M1 及更新）的 Mac。

2 GB 以上空闲空间

客户端自带运行环境，不用另装 Python 或其他依赖。再给 Bot 的工作文件留些空间。

一个聊天模型

灵策智算账号、其他服务商的 API Key 或本机模型都可以，首次启动时选择。

安装

一分钟装好。

  1. 运行安装程序

    双击 EXE，按向导完成安装，可以自选安装位置。

  2. 或者用免安装版

    先完整解压 ZIP，再双击里面的 Octop Bot.exe，并保留同目录的资源文件。

  3. 连接模型

    选择「开始使用」，登录灵策智算、填入 API Key 或选择本机模型。

  1. 打开 DMG
