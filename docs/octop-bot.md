# Octop Bot

双击独立客户端 **Octop Bot**，在欢迎页选择「开始使用」。个人工作区里有一位八爪鱼助手 Chief。首次配置聊天模型时，可以选灵策智算账号、其他云服务或本机模型，也可以点「稍后配置」先看新手引导。Windows 客户端自带 Python 和 Octop 服务，默认将数据保存在 `%USERPROFILE%\.octop-bot`。

没有灵策账号时，点「注册灵策智算账号」，在官网切到「注册」，用手机或邮箱完成验证，回到客户端登录。新手引导会介绍私聊、群聊和云端任务。在「第一条消息」里选一项任务，点「在 Chief 对话中编辑」，按自己的需求改写后再发送。点「跳过引导」可直接进入工作区。以后从「账号与模型 → 新手引导」可以重新打开。

选择「灵策智算账号」后，在系统浏览器里登录自己的灵策账号并确认授权。回到 Octop Bot，从账号可用的聊天模型中选择一个，保存后就可以向 Chief 或群成员发消息。模型调用由灵策按授权账号的积分和额度结算。在「账号与模型」里可以更换模型、切换到其他来源，或断开本机与灵策账号的连接。

已连接的灵策模型和已登录的云端工作区分别显示各自账号的积分余额。点「充值」可在系统浏览器打开灵策为当前账号签发的充值页。旧版模型授权首次充值时会提示「授权充值」，在灵策确认后即可继续。若模型连接已更新，请确认新显示的余额，再点「充值」。重新绑定后，需要从该账号可用的聊天模型中选一个并保存。返回客户端会自动刷新余额，也可以点击余额旁的刷新按钮。刷新失败时会标明上次查询的数值。

在灵策的授权页确认模型对话和积分充值权限时，可以设置每日积分上限。Octop Bot 用这项连接读取可用模型、发送聊天请求、查询余额，并为当前账号打开官方充值页。外部 ACP 工具自行管理模型，仅 Octop 原生 Bot 可以使用这项连接。

网页版和完整版桌面端也可以从左侧打开 **Octop Bot**。首次进入会为当前账号创建专属 Chief。账号、模型和会话保存在各自服务使用的 Octop 数据目录中。

桌面客户端左侧是团队通讯录。选择成员可以继续上次私聊，点击聊天顶部的名字可以查看资料或为该成员切换模型。左上角的「＋」可以创建 Bot 和群组，也可以用 `Ctrl+K`（macOS 上是 `⌘K`）搜索团队。Chief 和生成的角色头像会随对话状态变化，开启系统的「减少动态效果」后会显示静态头像。

找以前说过的话时，打开搜索，切到「历史私聊」，输入标题或消息关键词，按回车打开原会话。写群消息时可以带着草稿和已上传的附件切换会话，回来继续编辑；发送失败后点「重新发送」。在「账号与模型」中可以查看可用模型，并选择浅色、深色或跟随系统的外观。

## 用分组整理团队

右键点击通讯录空白处，选择「新建 Bot 分组」或「批量移组」。右键点击 Bot 或群聊后选择新建分组，会自动勾选当前条目，也可以在「移至分组」中选已有分组。使用键盘时，按 Tab 聚焦通讯录、成员或分组标题，再按 Shift+F10 或菜单键。触屏可点成员或分组旁的「⋯」，也可以长按通讯录空白处。

点击分组名可折叠或展开成员，右键点击标题可整理成员、改名、设置颜色、调整顺序或解散分组。置顶成员排在本组前面。解散分组会保留 Bot、群聊和消息。按 Ctrl+K 搜索分组名可以找到组内成员。

也可以直接告诉 Chief「建一个内容工作室分组，把选题策划和文案写作放进去」。如果要让这些成员一起工作，打开分组菜单，点「用组内 Bot 发起群聊」，核对成员和管理员后点「创建」。已有群聊不会被展开成新群的成员。

## 让 Bot 定时工作

点私聊顶部的 Bot 名字，在资料面板打开「定时任务」。填写任务要求，选择一次、每天、工作日或每周的执行时间并保存。时间以界面显示的服务时区为准。任务由本机 Octop 服务调度，执行期间需要保持服务运行。可以回到这里暂停或恢复任务。

同一面板里的「Token 用量」按所选时间范围显示这个 Bot 的模型调用次数和输入、输出 Token。灵策积分结算以账号账单为准。

## 关机后继续工作，换设备接着聊

在独立客户端的通讯录底部打开「云端工作区」，用灵策账号登录。另一台安装了 Octop Bot 的电脑登录同一灵策账号后，可以在「云端会话」打开原对话，查看云端回复并继续发送消息。退出客户端或关闭电脑后，灵策会继续处理已接收的云端任务。可以在会话内查看执行状态、回答 Bot 的问题，或停止本次执行。可用模型、云端执行权限和积分由当前灵策账号决定。

要把已有的本机私聊带过去，在这段对话里点 Bot 名字，选择「把当前私聊带到云端」，核对文字后确认。预览最多包含最近 20 条可见文字。附件、工具记录和思考过程不会随这次导入上传。也可以选择「在云端与这位 Bot 工作」开始一段新会话，使用该 Bot 的名称和职责。

在「云端定时任务」创建任务，选择时区对应的执行时间。电脑关机时，灵策调度器也会到点执行。任务运行后可以点「打开结果并续聊」。已有本机任务可先在 Bot 资料的「定时任务」中暂停，再用「用此配置创建云端任务」核对指令和时间，保存到云端。本机脚本、文件和应用依赖不会迁移到灵策运行环境。

## 从一句话建群

1. 在设置中配置一个支持工具调用的模型，然后打开 Chief。
2. 发送「帮我创建一个自媒体群组」。Chief 可以查询已有成员、补建专家并创建群。工具执行结束后，新成员和群会出现在左侧。
3. 打开群后直接提问，或用 `@` 指定成员。群设置可以调整管理员、成员及回复方式。在 Goal 中填写验收条件和分工，确认后可跟踪各阶段的回复和证据。

群成员交接工作后，管理员的最终回复会标为「团队汇总」。执行 Goal 时，成员的工作与管理员的复核会显示各自对应的阶段，重开群聊仍可查看。

Chief 默认使用 Octop 官方八爪鱼头像。选题策划、文案写作、视觉设计和数据运营分别使用黄色星星、紫色月亮、玫红宝石和青色六边形。其他 Bot 也会获得固定角色，重命名后会保留原形象。设置中可以调整角色与配色，或从自己的照片库选择头像。照片可批量导入并在多个 Bot 之间复用。群头像随成员变化，同一位成员在私聊和群聊中使用相同形象。

团队笔记供同一账号的 Bot 使用，群笔记和群文件由群成员共享。群中的成员使用独立的工作目录和会话。私聊中的「引用对话」可搜索历史；`/side` 可以就当前对话快照继续追问。需要隔离的专家可在 Bot 设置里开启隐私模式。删除隐私 Bot 后，可在保留目录列表中解除目录占用，文件仍保存在本机。

私聊达到当前模型的上下文压缩阈值时，Octop 会在同一会话内生成摘要，保留最近的原话继续工作。「引用对话」会标出命中消息的段号，点击即可插入该条原文。升级前的会话首次搜索时会从运行中的 Bot 检查点建立索引。Bot 也可以用 `read_own_chat` 按关键词找回当前私聊中的原话。

群输入框可上传本地文件，也可以选择本群已有的文件。发送后，成员能按消息中的路径读取附件，其他群聊无法访问这些附件。

## 本机启动

在仓库根目录运行以下命令可启动 Web 服务。

```powershell
uv run octop run --host 127.0.0.1 --port 8088
```

服务启动后打开 [本机 Octop Bot](http://127.0.0.1:8088/octop-bot)。

Windows 桌面开发版可用以下脚本启动。

```powershell
.\desktop\src\scripts\run-dev.ps1 -Bot
```

首次安装桌面开发依赖见 [desktop/README.md](../desktop/README.md)。

## 接入本机能力

- 第三方 IM 需要在「频道」配置相应平台的凭据并完成配对，然后在群设置中选择会话。已绑定的 IM 会话可以和群成员用文本交流。
- Office 文档预览使用本机 LibreOffice 和 Poppler。Word、Excel 和 PowerPoint 的生成文件可在工作目录中继续编辑。
- Windows 电脑控制使用可选的原生驱动。在仓库根目录运行 `uv sync --extra computer-use`。在非共享原生 Bot 私聊顶部打开「电脑控制」，选择运行中的应用并授予查看、后台操作或前台操作权限。Bot 可以读取指定窗口的辅助功能元素、点击控件或填写输入框。点「接管电脑」暂停后续操作，完成后点「交还给 Bot」。
